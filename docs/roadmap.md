# Roadmap

This roadmap describes portfolio-safe product direction. It is not an implementation commitment and does not add automation beyond observation.

## Completed In The Private Project

- Local notification receiver and dashboard server.
- Parser / resolver workflow for market-signal text.
- Missing Coordinate Queue.
- MAP8 review and high-confidence import workflow.
- Marker Builder and Marker Health.
- 24HR Statistics and Market Report JSON.
- Desktop Dashboard, Mobile Dashboard, Live Map, and Market Console.

## Portfolio-Safe Next Steps

- Add more sanitized screenshots and diagrams.
- Add unit-style examples for parser edge cases using fake data only.
- Improve documentation for recovery and manual operation workflows.
- Add public demo HTML snapshots that never read private runtime files.

## Explicit Non-Goals

- No automatic order acceptance.
- No LINE operation.
- No dispatch decision automation.
- No revenue prediction or driver scoring.
- No public runtime data or credentials.
