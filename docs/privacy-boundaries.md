# Privacy Boundaries

This public repository is designed for portfolio review. It intentionally excludes the private runtime layer.

## Excluded From Public Repo

- Real LINE raw messages.
- Real group names.
- Real addresses, phone numbers, and coordinates.
- API keys, tokens, passwords, and webhook URLs.
- `live-data/` runtime files.
- `notification_config.json` and private `place_aliases.json`.
- Logs, databases, caches, build outputs, and temporary files.

## Included Instead

- Sanitized source code.
- Example configuration files with placeholders.
- Demo data using `Group A`, `Group B`, `Demo Location`, and generic zones.
- Architecture and resume-oriented documentation.
- Sanitized screenshots.

DrivePilot Live is an observation system. It does not accept orders, operate LINE, score drivers, predict revenue, or make dispatch decisions.
